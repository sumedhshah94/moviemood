# MovieMood
UC Berkeley W210 Capstone Project for MIDS. Movie recommendation MVP that infers a user's mood from their recent song playlist and recommends a set of movies to watch. Group members include Neta Tartakovsky, Josie Ruggieri, Sumedh Shah, Neil Prabhu, and Will Dudek.

# Project Organization

    ├── LICENSE
    ├── README.md          <- The top-level README describing the project aims
    ├── data
    │   ├── raw            <- Data from third party sources.
    │   ├── interim        <- Intermediate data that has been transformed.
    │   └── processed      <- The final, canonical data sets for modeling.
    ├── notebooks          <- .ipynb notebooks. 
    ├── references         <- Data dictionaries, manuals, and all other explanatory materials.
    ├── reports            <- Generated analysis as HTML, PDF, LaTeX, etc.
    └── src                <- Source code for use in this project.
        └── data           <- Scripts to download or generate data
